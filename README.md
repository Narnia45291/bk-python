## วัตถุประสงค์

ระบบยืม-คืนหนังสือ (Library Borrow-Return System) พัฒนาขึ้นเพื่ออำนวยความสะดวกในการจัดการยืม-คืนหนังสือของห้องสมุดภายในวิทยาลัย
โดยช่วยให้ผู้ใช้งานสามารถยืมและคืนหนังสือได้อย่างสะดวก รวดเร็ว ลดขั้นตอนการทำงานแบบเดิมที่ต้องบันทึกด้วยกระดาษ
อีกทั้งยังช่วยให้เจ้าหน้าที่ห้องสมุดสามารถติดตามสถานะหนังสือ กำหนดวันคืน และคำนวณค่าปรับกรณีคืนเกินกำหนดได้อย่างถูกต้องและเป็นระบบ

## กลุ่มเป้าหมาย

- **นักศึกษา** — สามารถยืมและคืนหนังสือของห้องสมุดวิทยาลัยได้ผ่านระบบ
- **บุคลากรในวิทยาลัย** — สามารถยืมและคืนหนังสือได้เช่นเดียวกับนักศึกษา โดยอาจมีเงื่อนไขการยืม (เช่น จำนวนเล่ม/ระยะเวลา) ที่แตกต่างกันตามสิทธิ์ของแต่ละกลุ่ม

## ฟังก์ชันการทำงาน

ระบบประกอบด้วยฟังก์ชันหลัก 3 ส่วน ดังนี้

### 1. การยืมหนังสือ
ผู้ใช้งานสามารถเลือกหนังสือที่ต้องการยืมได้ โดยระบบจะตรวจสอบสิทธิ์และความพร้อมของหนังสือก่อนดำเนินการ เช่น ตรวจสอบว่าผู้ใช้ยังไม่เกินโควตาการยืม และหนังสือเล่มนั้นยังว่างอยู่ในระบบ เมื่อยืมสำเร็จ ระบบจะบันทึกข้อมูลการยืมและกำหนดวันครบกำหนดคืนโดยอัตโนมัติ

### 2. การคืนหนังสือ
ผู้ใช้งานสามารถคืนหนังสือที่ยืมไปได้ผ่านระบบ โดยระบบจะตรวจสอบวันที่คืนเทียบกับวันครบกำหนด หากคืนตรงเวลา ระบบจะอัปเดตสถานะหนังสือเป็น "ว่าง" ทันที แต่หากคืนล่าช้าเกินกำหนด ระบบจะคำนวณค่าปรับให้โดยอัตโนมัติ

### 3. การตรวจสอบระยะเวลาในการคืน
ระบบจะกำหนดวันครบกำหนดคืนให้ทุกครั้งที่มีการยืมหนังสือ และคำนวณจำนวนวันที่เกินกำหนด (ถ้ามี) เพื่อใช้คิดค่าปรับ พร้อมทั้งสามารถตรวจสอบรายการหนังสือที่ยังค้างคืนเกินกำหนดในระบบได้ เพื่อให้เจ้าหน้าที่ติดตามและแจ้งเตือนผู้ใช้งานได้ทันเวลา
